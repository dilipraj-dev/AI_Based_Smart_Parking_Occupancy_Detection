# Smart Parking AI — Power BI Analytics Dashboard Integration Guide

This guide documents the setup, data model, DAX measures, and visual components for the Power BI presentation dashboard connected to the real **Smart Parking AI** MobileNetV2 computer vision backend.

---

## 1. Data Source Architecture

The Power BI dashboard connects directly to the live output generated by the FastAPI inference engine:
- **File Source**: `outputs/powerbi/parking_occupancy.csv`
- **Web Source (Alternative)**: `http://localhost:8000/powerbi-files/parking_occupancy.csv`
- **API Endpoint**: `http://localhost:8000/powerbi/data`

### Data Schema (10 Fields)
| Column Name | Data Type | Role / Categorization |
| :--- | :--- | :--- |
| `Date` | Date (`YYYY-MM-DD`) | Ingestion Date |
| `Time` | Time (`HH:MM:SS`) | Ingestion Time |
| `Parking_Lot` | Text | Facility Identifier (`Parking_Lot_5`) |
| `Slot_ID` | Text | Categorical Slot Key (`SLOT_001` - `SLOT_049`) |
| `Status` | Text | Categorical Class (`OCCUPIED` / `VACANT`) |
| `Confidence` | Decimal (`0.00` - `100.00`) | MobileNetV2 Sigmoid Confidence % |
| `Total_Slots` | Integer | Total Configured Capacity (`49`) |
| `Occupied_Slots` | Integer | Count of Occupied Bays (`27`) |
| `Vacant_Slots` | Integer | Count of Vacant Bays (`22`) |
| `Occupancy_Percentage`| Decimal (`0.00` - `100.00`) | Real Occupancy Ratio (`55.10%`) |

## 2. DAX Measures (`powerbi/measures.dax`)

Enter these verified DAX measures in Power BI Desktop under the `parking_occupancy` table:

```dax
// Total capacity
Total Slots = COUNTROWS('parking_occupancy')

// Occupied slot count
Occupied Slots = 
CALCULATE(
    COUNTROWS('parking_occupancy'),
    'parking_occupancy'[Status] = "OCCUPIED"
)

// Vacant slot count
Vacant Slots = 
CALCULATE(
    COUNTROWS('parking_occupancy'),
    'parking_occupancy'[Status] = "VACANT"
)

// Dynamic Occupancy %
Occupancy % = 
DIVIDE([Occupied Slots], [Total Slots], 0)

// Average AI Classification Confidence
Average Confidence = 
DIVIDE(AVERAGE('parking_occupancy'[Confidence]), 100, 0)
```

> **Formatting Notes**:
> - Format `Occupancy %` as **Percentage** with 2 decimals (e.g., `55.10%`).
> - Format `Average Confidence` as **Percentage** with 2 decimals (e.g., `95.83%`).
> - Set Default Summarization for `Slot_ID` to **Don't Summarize**.
> - Set Default Summarization for `Confidence` to **Average** (never SUM).

## 3. Required Dashboard Visuals

### 1. KPI Cards Row
- **Card 1**: `[Total Slots]` (Display: `49`)
- **Card 2**: `[Occupied Slots]` (Display: `27`, Data label color: Rose `#F43F5E`)
- **Card 3**: `[Vacant Slots]` (Display: `22`, Data label color: Emerald `#10B981`)
- **Card 4**: `[Occupancy %]` (Display: `55.10%`)
- **Card 5**: `[Average Confidence]` (Display: `95.83%`, Data label color: Cyan `#38BDF8`)

### 2. Occupancy Distribution Visual
- **Visual Type**: Donut Chart
- **Legend**: `Status` (`OCCUPIED`, `VACANT`)
- **Values**: `[Occupied Slots]`, `[Vacant Slots]`
- **Colors**:
  - `OCCUPIED`: `#F43F5E` (Rose)
  - `VACANT`: `#10B981` (Emerald)

### 3. AI Prediction Confidence Analysis
- **Visual Type**: Clustered Column / Bar Chart
- **X-Axis / Axis**: `Slot_ID` (Categorical, sorted ascending)
- **Y-Axis / Values**: `Average of Confidence`
- **Legend**: `Status`
- **Data Colors**: `#F43F5E` (Occupied), `#10B981` (Vacant)
- **Constant Line**: Y = 90 (High-confidence benchmark)

### 4. Slot Status Telemetry Table
- **Visual Type**: Table
- **Columns**: `Slot_ID`, `Status`, `Confidence`
- **Conditional Formatting**: Background or Font Color on `Status` (Rose for Occupied, Emerald for Vacant)

### 5. Facility & Analysis Metadata
- **Card / Multi-row card**:
  - Facility: `Parking Lot 5`
  - Ingestion Snapshot: `Date` & `Time`
  - Model: `MobileNetV2 Spatial Binary Classifier`
